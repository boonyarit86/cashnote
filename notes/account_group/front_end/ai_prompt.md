# feature: Account Group

- some sample value (dynamic) in the future of “Assets” will be child such as “bank”, “investment”, “cash”
- some sample value (dynamic) in the future of “Liabilities” will be child such as “credit card”, “loan”

### UI Requirement

- create a page named “Account”
- there must have 2 section
- the first section is “Assets”
- the second is “Liabilities”
- “Assets” & “Liabilities” are a section title
- “Assets” & “Liabilities” use the same component
- display the two accounts ordering vertically
- each account group displayed should support custom child component in the future

### User Journey

1. open website (active any page)
2. click “hamburgur” icon in order to open the sidebar
3. click “Account” menu
